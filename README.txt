CÓMO PUBLICAR

1. Sube toda esta carpeta al hosting.
2. La carpeta debe llamarse, por ejemplo:
   nuevainterfazdisenadores
3. Dentro deben quedar:
   index.html
   styles.css
   script.js
   assets/

URL final esperada:
https://www.latostadora.com/nuevainterfazdisenadores/

También puedes publicar la carpeta en Netlify Drop, GitHub Pages, Cloudflare Pages
o cualquier hosting estático.

IMPORTANTE:
No abras solamente index.html fuera de la carpeta. Debe conservar las rutas
styles.css, script.js y assets/.
